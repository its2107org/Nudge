# Nudge

A reminder app that rings like an alarm and keeps nagging until you tap **Done**.

- Reminders for anything: every few days and hours (e.g. every 3½ days), or on set days of the week.
- Proper alarms (AlarmKit) that sound on silent, plus repeat notifications every few minutes until done.
- Home Screen and Lock Screen widgets with a Done button.
- Siri: "Mark Nudge done", "When's my next Nudge".
- Injection spot rotation, doses-left-in-pen counter, and a shareable history.

Built in the cloud with GitHub Actions and delivered through TestFlight, using the same
Apple details as the owner's other browser-built apps. A fresh build goes out on the
1st of every month so TestFlight never expires.
